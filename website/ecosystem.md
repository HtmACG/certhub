# 生态集成

CertHub 内置 **53 项**开箱即用的集成（CA 品牌 + 部署与接入能力），另有 **75 个部署插件**、**12 种签发来源**、**41 种授权类型**与 **10 种通知渠道**。所有图标都取自项目真实资源，不依赖任何外部 CDN —— 内网、离线环境同样正常显示。

## 证书颁发机构

| 机构 | 说明 | 是否需 EAB |
| --- | --- | --- |
| Let's Encrypt | 公益 CA，DV 证书 90 天，ACME 协议的发起者 | 否 |
| Google Trust Services | Google 旗下免费 DV CA，90 天 | **是**（Key 7 天失效） |
| ZeroSSL | 免费 DV，支持 ACME，首次使用自动换取 EAB | 是（可自动） |
| FreeSSL / LiteSSL | 亚洲诚信出品，ACME v2，必须带 EAB | **是**（一次性） |
| Buypass | 挪威 CA，免费 180 天 | 否 |
| 自定义 CA | 对接企业私有 ACME，填目录地址即可 | 视 CA |

> 以上商标及标识归其各自所有者所有，仅用于标示可在本平台申请的证书品牌。

## 接入方式

如果某个平台不在清单里，还有三条通用路径：

1. **主机 SSH / 执行远程主机命令**：把证书传到任意 Linux 机器，然后执行你自己的重载命令。
2. **Webhook（推送到自定义接口）**：把证书推给你的系统，由对端完成安装。
3. **脚本部署**：在目标主机执行脚本，脚本里自己决定把证书放到哪、怎么重载。

::: tip 想要某个插件？
插件清单由后端 `plugins.py` 的注册表决定，新增一个插件只需要「写 handler + 注册 + 登记元数据」三步，前端表单会自动出现。做法见 [新增插件](/docs/plugin-dev)。
:::
